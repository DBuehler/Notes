# Updated - Vite

`npm create vite@latest` will prompt to answer all the questions - can choose Typescript and frameworks.

```sh
$ npm create vite@latest
```

# Commands

- `npm run dev` - To run the development server
- `npm run build`
- `npm run devhost` - To run the development server in hosting mode (after adding devhost command below)

# Some changes

Add to `package.json` > `scripts`: `"devhost": "vite --host",`
